# 🎧 Primeros pasos

```text
① Abre la terminal ─► ② escribe: muzoryn ─► ③ elige tu carpeta de música ─► ④ pulsa 2 ─► ⑤ Enter ▶
```

1. Escribe `muzoryn` y pulsa Enter. La **primera vez** abre un navegador de carpetas para que elijas dónde está tu música: `Enter` entra en una carpeta, `s` añade la carpeta actual, `Backspace` sube.
2. Pulsa `2` (**Biblioteca**): carpetas a la izquierda, canciones a la derecha. Muévete con `↑`/`↓` y cambia de panel con `Tab`.
3. `Enter` reproduce. `Espacio` pausa, `n`/`p` cambian de pista, `=`/`-` el volumen.
4. `w` cierra la ventana **sin parar la música**. `W` (mayúscula) sale del todo.

Añadir o quitar carpetas más tarde: `Alt+M` (incluye USB y discos externos). También puedes abrir archivos o carpetas directamente:

```bash
muzoryn ~/Descargas/MiAlbum
muzoryn cancion.flac otra.mp3
```
